# VIRUSTRA — Reference Library & Competitive Playbook

**Purpose:** one place to record every reference site the client/owner shares — design, colour, typography, brand quality, marketing tactics — and what Virustra must do to match (target: **at least 10–15% of their level**) or beat them. Add each new reference as a new `## REF-xx` block using the template at the bottom.

**Rules for using references:** study structure, rhythm, hierarchy, tactics. **Never copy** their photography, copy, logos or code. Observations below are things seen on the live site on 2026-10-09; items marked *(inference)* are interpretation of why they do it, not verified facts.

---

## REF-01 — House of Masaba (houseofmasaba.com) — *"best reference for image and style"*

### What it is
Premium Indian designer label (womenswear, menswear, bridal, jewellery) selling online and in a few boutiques. Brand = bold, modern-heritage, celebrity-adjacent.

### Visual system (observed)
| Area | Observation |
|---|---|
| Photography | One cohesive "world" per season: dark teal-black backdrop, a single hero prop (a boat, jasmine in hair, a carved mask), model in motion, garment detail lit with warm key light. Always full-bleed, very high-fidelity, same colour grade across every image. |
| Palette | Near-black `#000`, deep green-black image backdrops, white `#fff` canvas, off-white `#FAF9F5`, greys `#868686`/`#545454` for secondary text, **announcement bar deep red `#520105`**, **SALE link red `#DB1215`**, dusty rose block (footer "House Directory" panel). Almost no ornament colour: the clothes carry the colour. |
| Typography | **Montserrat** (400/500/600/700) for everything: UI, nav, headings, body. Uppercase + tracking for nav, labels and captions; light weight, sentence-case for section titles. **Urbanist** also loaded (accent/secondary). |
| Components | Thin outlined "Shop Now" ghost buttons on hero; 4-up category carousel with centred uppercase captions; generous white space; tiny cart/wishlist counters; floating green WhatsApp button; yellow accessibility/utility widget. |
| Motion | Restrained: slideshow transitions, hover image swaps, carousel arrows. Quality comes from photography, not animation. |

### Information architecture (observed)
1. Announcement bar — rotating "Festive 2026 · Free Shipping*" (red, always visible).
2. Header — currency selector, centred logo, search / account / wishlist / cart; nav **Women · Men · Bridal · Jewellery · Sale (red)** with mega-menus (Sarees, Kurta & Sets, Kaftans, Fusion Sets, Lehengas, Dresses, Co-ords, "New In", **"Ready to Ship"**, **"Celebrity Spotlight"**).
3. Full-screen hero slideshow (campaign-led, 1 CTA each).
4. "For every occasion" category carousel.
5. Video / editorial banners.
6. Collection lists + featured collections with **"Ready To Ship"** tags.
7. **Celebrity Spotlight** (social proof through public figures wearing the pieces).
8. **"Masaba in Time"** heritage / story block.
9. Slideshow of more campaigns.
10. **"House Directory"** — big store photo + store locator link.
11. Footer: newsletter ("get me on the list"), Details · Policies · Information · Need help, support phone/email, grievance officer, socials, legal entity + CIN.

### Marketing strategy (observed → inference)
- **Seasonal framing** ("Festive 2026") on the bar + hero → urgency without discount-shouting *(inference: protects brand premium)*.
- **Free shipping with an asterisk** as the standing conversion lever.
- **Sale lives in the nav in red**, not on the hero → discounts are present but never cheapen the brand.
- **Ready-to-ship tagging** → removes the biggest online-ethnic-wear anxiety (waiting) *(inference)*.
- **Celebrity spotlight** → borrowed trust/aspiration.
- **Store directory + WhatsApp + support contacts** → omnichannel reassurance for high-ticket purchases.
- **Newsletter list** → owned audience for launches.
- **Legal & grievance transparency** in footer → Indian e-commerce compliance and trust.

### "Match ≥10–15%" checklist (what actually moves us there)
**Can be done in the website now (v2 covers these):**
- [x] Announcement bar with rotating offers + countdown.
- [x] Women / Men / Kids top-level navigation, with dropdowns and a red Sale link.
- [x] Full-bleed carousel hero with one CTA per slide (8 banners).
- [x] "Ready to ship / available to rent" style tags and SALE badges with struck-through prices.
- [x] Category carousel with centred uppercase captions and ghost buttons.
- [x] Montserrat / Urbanist font option + selectable colour theme + accessibility controls.
- [x] Store-style "directory" block and a redesigned, fuller footer.
- [x] Floating WhatsApp button.

**Needs the business (cannot be faked):**
- [ ] A real photo shoot with one colour grade and one set story per season (this alone is ~60% of the perceived quality gap).
- [ ] Real prices, discounts, shipping promise, return policy, GST/legal entity details, grievance officer.
- [ ] Real customer/celebrity/influencer proof with permission.
- [ ] Store/atelier address if there is one.

### Where Virustra can go beyond (the "more than 10–15%")
1. **Rent + buy on the same product** (Masaba cannot offer this) — lead with it in every banner.
2. **WhatsApp-native enquiry builder** with product + date + size pre-filled.
3. **Kids + family bundles** — a "dress the whole family" banner and bundle offer (Masaba has no kids range).
4. **Motion identity** (arch reveals, pinned scenes, needle cursor) — more distinctive than their static slideshow.
5. **Occasion-first discovery** (Wedding / Garba / Festival / Engagement) with date-based availability check.

### Fonts / theme decisions taken from this reference
- Added **Montserrat (headings) + Urbanist (body)** as a switchable font set.
- Added **Masaba-style "Noir" theme** (deep green-black, deep red accent, off-white) as a switchable theme; Virustra's own rose-gold + maroon remains default.
- Sale red `#DB1215`-family and announcement-bar red `#520105`-family adopted as the sale/urgency colours.
